# lightsync

Synchronize RGB smart lights (Govee and similar) directly over **Bluetooth LE** or **local Wi-Fi (LAN)** — no cloud required.

## Goals

- Discover nearby lights over BLE and on the local network
- Control power, color, brightness, and scenes per device
- Keep multiple lights in sync (same color/effect, low latency)
- Pluggable device protocols so other brands can be added
